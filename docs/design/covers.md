# Обложки статей — шаблон

Правило введено 17.11.2026 владельцем. Все обложки статей делаются по одному шаблону
`docs/design/cover-template.svg`, отличаются только текстом.

**Подтверждено 20.11.2026: правило обязательно для всех последующих обложек** —
Telegram, VK, Дзен. Формула одна: **одно крупное жирное слово темы + подпись под
ним**. Любая обложка, которая ломает эту формулу (старая jpg-серия, генератор
картинок, чужой шаблон), в ленту не идёт. Повод: пост про GEO ушёл с обложкой из
прежней серии — в ленте он выбился из ряда, владелец его отклонил.

## Композиция

1. **1200×630**, PNG для загрузки на площадки (Дзен требует ≥700 px по ширине).
2. Левая часть (~2/3) — светлый мраморный фон с лёгким зерном.
3. Сверху слева — вордмарк `AI-TRAFFIC PRO`, чёрный, с разрядкой.
4. Крупное чёрное слово темы (у первой обложки — `GEO`), под ним оранжевая линия `#F2610C`.
5. **Линия идёт до правого края страницы.** При пересечении с тераkотовым блоком
   меняет цвет на бежевый — как фон (`#F7F4EF`). То есть физически это две линии
   в одной строке: оранжевая до `x=820`, бежевая от `x=820` до `x=1200`.
6. Справа — сплошной тераkотовый блок `#F2610C` во всю высоту, в нём белое число
   и подпись прописными (`14 ПРОВЕРОК`).
7. Под линией — 1–2 строки описания, внизу слева домен `ai-traffic-pro.ru`.

## Как собрать новую обложку

1. Скопировать шаблон: `cp docs/design/cover-template.svg public/blog/<slug>-cover.svg`.
2. Заменить тексты: крупное слово, число в блоке, подпись под числом, 1–2 строки описания.
3. Отрендерить в PNG (Inkscape на машине сломан, рендерим Chrome):
   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
     --hide-scrollbars --force-device-scale-factor=1 --window-size=1200,630 \
     --screenshot=public/blog/<slug>-cover.png "file://$PWD/public/blog/<slug>-cover.svg"
   ```
4. Проверить размеры: `sips -g pixelWidth -g pixelHeight <файл>` → 1200 и 630.
5. Выложить на сайт и убедиться, что файл отдаёт 200 **до** публикации поста:
   Telegram скачивает обложку по ссылке, локальный файл ему не виден.
   `curl -I https://ai-traffic-pro.ru/blog/<slug>-cover.png`
6. Пост отправляется без ручного `--photo`: `tools/tg-publish/send.py` и
   `src/pages/distribution/manifest.json.ts` ищут обложку по имени
   `<slug>-cover.png` и подставляют сами.

## Текст на обложке

| Место | Что | Ограничение |
|---|---|---|
| Крупное слово | тема, одно слово | 3–7 знаков, капсом, без точки |
| Число в блоке | главная цифра статьи | 1–2 знака |
| Подпись под числом | что это за цифра, прописными | 6–16 знаков |
| Строки описания | 1–2 строки по делу | до 32 знаков каждая |

Формула одна: **одно крупное жирное слово, под ним пояснение**. Два равных по
весу слова — это уже не этот шаблон.

**Слово не заходит на тераkотовый блок.** Правило от 20.11.2026: правый край
текста — не дальше `x=800`, блок начинается на `x=820`. Кегль подбирается по
фактической ширине (`fit_word` в `tools/publish/cover.py`), а не по числу букв;
если слово не влезает и на минимальном кегле — режется на **две строки, обе на
бежевом поле**. Лучше две строки, чем буква поверх плашки.

Проверка после сборки — глазами или скриптом: в области блока (x 810–1200,
y 200–425) не должно быть тёмных пикселей, кроме белой цифры.

Пересобрать все обложки после правки шаблона: `python3 tools/publish/cover.py --refit`.

## Чего не делать

- Не менять цвета фона и блока: тераkота `#F2610C` — единственный акцент.
- Не ставить фото, людей, градиенты, тени.
- Не писать на обложке больше одного крупного слова и двух строк описания.
- Не отдавать обложку генератору изображений: он искажает буквы (дважды отказал
  по security policy 17.11.2026, ручная вёрстка дала точный текст).
- **Не переиспользовать старые обложки** `<slug>.jpg` из серии 16.11.2026 и
  `<slug>-square.jpg`: это прежнее оформление. Если для статьи есть подходящая
  картинка в новом стиле (например, `dzen-<slug>.png`), её кладут как
  `<slug>-cover.png`, а не подключают старую через `--photo`.
- Не публиковать пост, пока обложка не отдаёт 200 по адресу на сайте: тогда
  Telegram покажет превью ссылки внизу вместо картинки сверху, и пост уйдёт
  «без обложки».
