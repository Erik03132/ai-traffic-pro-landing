# Спецификация: мультилендинг страницы услуги

Единый визуальный и содержательный стандарт для 7 страниц услуг
(`src/pages/services/[slug].astro` + `src/data/services/*.ts`).

Эталон, с которого стандарт начался — **SEO-страница**. Всё остальное
приведено к нему. Документ фиксирует: архитектуру, типографику, палитру,
компоненты, модель данных и правила текста.

- Шаблон: `src/pages/services/[slug].astro`
- Данные: `src/data/services/<slug>.ts`, типы — `src/data/types.ts`
- Токены: `src/styles/global.css` (`@theme`, Tailwind 4)
- Реестр услуг: `src/data/services/index.ts` (`SERVICES` — 6 основных, `ALL_SERVICES` — все 7)

## 1. Архитектура страницы

Порядок секций фиксирован. Меняется только состав «сервисных» блоков (04.5–04.7).

| № | Секция | Eyebrow | Фон | Обязательна |
|---|--------|---------|-----|-------------|
| 0 | Хлебные крошки | — | `bg-white` | да |
| 1 | Hero (H1 + подзаголовок + CTA + сайдбар) | — | `bg-white` | да |
| 2 | Проблемы | `[01 / ПРОБЛЕМЫ]` | `bg-stone-50` | да |
| 3 | Как это работает (таймлайн) | `[03 / КАК ЭТО РАБОТАЕТ]` | `bg-white` | да |
| 4 | Как решаем (нумерованные карточки) | `[04 / КАК РЕШАЕМ]` | `bg-white` | да |
| 5 | Сервисный блок A | `[04.5 / …]` | `bg-white` | зависит от услуги |
| 6 | Сервисный блок B | `[04.6 / …]` | `bg-stone-50` | зависит от услуги |
| 7 | Сервисный блок C | `[04.7 / …]` | `bg-white` | зависит от услуги |
| 8 | FAQ | `[06 / ВОПРОСЫ И ОТВЕТЫ]` | компонент `Faq` | да |
| 9 | Заявка | `[07 / ЗАЯВКА]` | `bg-stone-100` | да |

**Ритм фона:** секции чередуются `white → stone-50 → white`. Два одинаковых
фона подряд не ставим — границу держит ещё и `border-b border-stone-200`.

**Нумерация сквозная 01→07.** Никаких `[05]`, `[06]` на месте сервисных
блоков: они всегда `04.5 / 04.6 / 04.7`, чтобы основная нумерация не ехала
при добавлении блоков.

**Отступы секции (одинаковые везде):**

```html
<section class="w-full border-b border-stone-200 bg-white py-20 md:py-28">
  <div class="max-w-[1280px] mx-auto px-margin md:px-margin-desktop">
```

## 2. H1 — правила

H1 хранится в данных одной строкой, строки разделены символом `|`:

```ts
h1: 'SEO, GEO и видимость в ИИ:|сайт находят и в поиске и в нейросетях'
```

Шаблон режет по `|` и вторую строку оборачивает в `.accent-italic`.

| Правило | Как |
|---|---|
| Ровно **2 строки** | Один `|`, не больше |
| Строка 1 — суть услуги | Обычный Plus Jakarta Sans Light, `text-stone-900` |
| Строка 2 — обещание/выгода | `.accent-italic` — терракота, Instrument Serif italic |
| Двоеточие | Ставится в конце **первой** строки, если вторая — раскрытие: `'Привлечение клиентов и воронка продаж:|заявки окупаются'` |
| Без дублей | Строка 2 не повторяет строку 1 другими словами |
| **Строка 2 — в одну визуальную строку** | Иначе фраза рвётся на неудобном месте |
| Длина строки 2 | ≤ ~25 символов при 60px ≈ 500px; больше — перенос |
| Без «Искусственные товары…» | Вторая строка всегда про эту услугу, не про другую |

**Как проверить, что строка 2 не переносится:**

```js
const h1 = document.querySelector('main h1');
const cs = getComputedStyle(h1);
[...h1.querySelectorAll('span.block')].map(s => ({
  text: s.firstElementChild.innerText,
  lines: Math.round(s.firstElementChild.getBoundingClientRect().height / parseFloat(cs.lineHeight)),
}));
// ожидаем: [{lines: 1 или 2 — строка 1}, {lines: 1 — строка 2}]
```

**Разметка:**

```html
<h1 class="text-4xl sm:text-5xl lg:text-6xl font-light text-stone-900 tracking-tight leading-[1.06] mb-5">
  {service.h1.split('|').map((line, i) => (
    <span key={i} class="block" style={{ display: 'block' }}>
      {i === 0 ? <span>{line}</span> : <span class="accent-italic">{line}</span>}
    </span>
  ))}
</h1>
```

## 3. Заголовки H2 и H3

**H2 секции** — всегда в одном из двух вариантов:

```html
<!-- A: заголовок слева, описание под ним (для блоков с 3+ карточками) -->
<div class="mb-14">
  <span class="font-mono-label text-mono-label uppercase text-terracotta-600 tracking-widest font-semibold block mb-2">
    [04.5 / ПЛОЩАДКИ]
  </span>
  <h2 class="text-3xl sm:text-4xl font-light text-stone-900 tracking-tight leading-tight">
    Где ведём&nbsp;<span class="accent-italic">соцсети</span>
  </h2>
  <p class="font-body-md text-body-md text-stone-700 leading-relaxed mt-3 max-w-3xl">…</p>
</div>

<!-- B: двухколоночная раскладка 5/7 — текст слева, карточки справа -->
<div class="grid grid-cols-1 lg:grid-cols-12 gap-12 lg:gap-16">
  <div class="lg:col-span-5"> …eyebrow + h2 + p… </div>
  <div class="lg:col-span-7"> …карточки… </div>
</div>
```

| Правило | Значение |
|---|---|
| Классы H2 | `text-3xl sm:text-4xl font-light text-stone-900 tracking-tight leading-tight` |
| Акцент | Последний смысловой сегмент в `.accent-italic`, 1–3 слова |
| Неразрывный пробел | `&nbsp;` перед акцентом — чтобы предлог не остался висеть в конце строки |
| H3 в карточках | `text-xl sm:text-2xl lg:text-3xl font-light` (крупные) или `text-lg sm:text-xl font-medium` (компактные) |

## 4. Eyebrow (моно-рубрика)

```html
<span class="font-mono-label text-mono-label uppercase text-terracotta-600 tracking-widest font-semibold block mb-2">
  [01 / ПРОБЛЕМЫ]
</span>
```

| Правило | Значение |
|---|---|
| Формат | `[NN / НАЗВАНИЕ]` — скобки, номер, слэш, пробелы |
| Регистр | ВСЕГДА UPPERCASE |
| Длина названия | 1–2 слова, не дублирует H2 под собой |
| Цвет | `text-terracotta-600` (`#ea580c`) |
| Шрифт | JetBrains Mono 12px, `tracking-widest`, `font-semibold` |

**Утверждённые названия:** `ПРОБЛЕМЫ`, `КАК ЭТО РАБОТАЕТ`, `КАК РЕШАЕМ`,
`ВОПРОСЫ И ОТВЕТЫ`, `ЗАЯВКА` + сервисные (см. §9).

## 5. Типографика

Шрифты подключены в `Base.astro`, объявлены в `@theme` (`global.css`).

| Роль | Шрифт | Токен / класс | Размер |
|---|---|---|---|
| Заголовки, текст | **Plus Jakarta Sans** | `--font-sans` | — |
| Курсивный акцент | **Instrument Serif** (italic, 400) | `.accent-italic` | наследует |
| Рубрики, номера, метки | **JetBrains Mono** | `--font-mono`, `font-mono-label` | 12px |
| Иконки | **Material Symbols Outlined** | `.material-symbols-outlined` | 16–24px |

**Шкала:**

| Токен | Размер | line-height | Где |
|---|---|---|---|
| `text-display-hero` | `clamp(2.5rem, 5.4vw, 4.5rem)` | 1.06 | главная |
| H1 услуги | `text-4xl sm:text-5xl lg:text-6xl` | `leading-[1.06]` | hero |
| H2 секции | `text-3xl sm:text-4xl` | `leading-tight` | все секции |
| H3 крупный | `text-xl sm:text-2xl lg:text-3xl` | `tracking-tight` | карточки |
| H3 компактный | `text-lg sm:text-xl` (`font-medium`) | — | плотные сетки 4–6 колонок |
| `text-body-lg` | 1.125rem | 1.65 | подзаголовок hero, вводный абзац |
| `text-body-md` | 1rem | 1.6 | текст карточек-описаний |
| `text-body-sm` | 0.875rem | 1.5 | текст в карточках |
| `text-mono-label` | 0.75rem | 1.2 | eyebrow, метки |

**Веса:** заголовки — `font-light` (300), кроме компактных H3 (`font-medium`).
Никакого `font-bold` в заголовках — контраст держится размером, а не весом.

**`.accent-italic`** — не просто курсив, а компенсированный оптически:
`scale(0.94, 0.97)` + `transform-origin: left baseline`, чтобы Instrument Serif
(единственный вес 400) не выглядел тяжелее Jakarta Light.

## 6. Палитра

Три группы. Правило пропорций: **70 % stone / 20 % white / 10 % terracotta**.

### Stone — фон, текст, границы

| Токен | HEX | Назначение |
|---|---|---|
| `stone-50` | `#faf8f5` | фон страницы, чередующиеся секции |
| `stone-100` | `#f5f2eb` | подложка hero-сайдбара, секция «Заявка» |
| `stone-200` | `#eae5d9` | **все границы**: `border-stone-200` |
| `stone-300` | `#dcd5c6` | hover-границы |
| `stone-400` | `#a8a29e` | подписи-метки внутри карточек («МЕТРИКА») |
| `stone-700` | `#52525b` | основной текст абзацев |
| `stone-800` | `#27272a` | текст body по умолчанию |
| `stone-900` | `#18181b` | заголовки, цифры, кнопка CTA |

### Terracotta — единственный акцент

| Токен | HEX | Назначение |
|---|---|---|
| `terracotta-600` | `#ea580c` | eyebrow, `.accent-italic`, иконки, номер карточки |
| `terracotta-700` | `#c2410c` | `--color-error` |

Терракота **не используется** для фонов карточек и крупных плашек — только
текст, иконки, тонкие акценты.

### Sage — статус/сроки

| Токен | HEX | Назначение |
|---|---|---|
| `sage-50` | `#ecfdf5` | фон чипа срока |
| `sage-200` | `#a7f3d0` | граница чипа |
| `sage-600` | `#0d9488` | иконка `schedule`, `check_circle` |
| `sage-700` | `#0f766e` | текст чипа срока |

### Бейдж услуги в hero

```html
<span class="px-2.5 py-0.5 rounded border border-[#BFDBFE] bg-[#EFF6FF] text-terracotta-600 font-mono-label text-mono-label font-semibold tracking-wider uppercase flex items-center gap-1.5">
  <span class="material-symbols-outlined text-base align-middle">{service.icon}</span>
  {service.badge}
</span>
```

Формат бейджа: `ОБЛАСТЬ + ОБЛАСТЬ` — `ЗАЯВКИ + ВОРОНКА`, `CRM + АВТОМАТИЗАЦИЯ`,
`ПОИСК + AI`, `SMM + КОНТЕНТ`, `РЕКЛАМА + АНАЛИТИКА`, `САЙТ + ЛЕНДИНГ`,
`E-COM + МАРКЕТПЛЕЙСЫ`. Одно слово — только если второго честно нет.

## 7. Компоненты

### 7.1 Карточка — базовая единица

```html
<div class="rounded-2xl border border-stone-200 bg-white p-8">
```

| Вариант | Классы |
|---|---|
| Белая (на `stone-50` секции) | `rounded-2xl border border-stone-200 bg-white p-8` |
| Тонированная (на `white` секции) | `rounded-2xl border border-stone-200 bg-stone-50 p-8` |
| Растянутая по высоте | `+ flex flex-col`, текст `flex-1` |
| Компактная (сетки 4–6 колонок) | `+ p-6`, H3 `text-lg sm:text-xl font-medium` |

Радиус всегда `rounded-2xl` (16px). Тени у карточек **не используются** —
только граница. Тень есть только у hero-сайдбара и формы.

### 7.2 Hero

Двухколоночная сетка `lg:grid-cols-12`: слева `lg:col-span-8` (номер + бейдж,
H1, подзаголовок, одна кнопка), справа `lg:col-span-4` — сайдбар-сводка.

```html
<!-- Сайдбар: 4 строки, разделённые border-t -->
<div class="rounded-2xl border border-stone-200 bg-stone-100 p-6 space-y-5">
  Метрика → service.metric
  Кому подходит → service.forWhom
  Что получите → service.outcomes.slice(0, 3)
  Стоимость: по запросу
</div>
```

**Одна кнопка в hero:** `Оставить заявку` → `#lead`. Никаких «позвоните»,
«скачайте», «узнать цену» рядом. Иконка `arrow_outward` в кнопке.

### 7.3 Секция «Проблемы»

`grid-cols-1 md:grid-cols-3`, ровно **3 карточки**, иконка `report_problem`
в терракоте, H3 + абзац. Заголовок секции: `С какими проблемами приходят`.

### 7.4 Секция «Как это работает» — вертикальный таймлайн

Ключевой паттерн: вертикальная линия + круглые номера + чип срока.

```html
<div class="relative">
  <div class="hidden lg:block absolute left-[70px] top-[7px] bottom-[7px] w-px bg-stone-200" />
  <div class="space-y-10 lg:space-y-16">
    <!-- номер -->
    <div class="w-14 h-14 rounded-full bg-white border-4 border-stone-200 flex items-center justify-center font-mono-index text-mono-index font-semibold text-terracotta-600 group-hover:border-terracotta-600">
    <!-- срок -->
    <span class="inline-flex items-center gap-2 px-3 py-1.5 rounded-full border border-sage-200 bg-sage-50 font-mono-label text-mono-label uppercase tracking-wider text-sage-700">
```

Ровно **4 шага**. У каждого обязателен `period` (срок).

### 7.5 Секция «Как решаем» — нумерованные карточки

`grid-cols-1 md:grid-cols-2`, ровно **4 карточки**, номер — тот же круглый
бейдж `w-14 h-14` слева от H3.

### 7.6 Сервисный блок — 4 варианта сетки

| Сетка | Когда | Пример |
|---|---|---|
| `md:grid-cols-2` | 4 крупные карточки | Площадки, Типы сайтов, Карточка товара |
| `md:grid-cols-2 lg:grid-cols-3` | 6 средних карточек | Каналы привлечения, Площадки продаж |
| `md:grid-cols-2 lg:grid-cols-4` | 4–6 компактных с иконкой | Единый каталог, Чек-лист запуска |
| `md:grid-cols-2 lg:grid-cols-5` | 5 этапов процесса | Этапы воронки |

Карточки без иконки — для «площадок/каналов» (там важен текст, не глиф).
Карточки с иконкой — для «форматов/проверок» (иконка = быстрый ориентир).

### 7.7 Чипы (теги форматов)

```html
<span class="px-3 py-1.5 rounded-full border border-stone-200 bg-white font-body-xs text-body-xs text-stone-700">
```

### 7.8 FAQ и форма

Компоненты `Faq.astro` / `LeadForm.astro`. FAQ — `<details>`, 13–15 вопросов.
Форма — единственный `id="lead"` на странице.

## 10. Правила текста

1. **Без блока «Кому подходит»** как отдельной секции. `forWhom` живёт только
   одной строкой в сайдбаре hero.
2. **Одна услуга = одна страница = одно обещание.** Не «всё про маркетинг».
3. **Конкретика вместо прилагательных.** Не «качественно и профессионально»,
   а «проходит модерацию с первого раза».
4. **Цифры в тексте**, а не в сносках: сроки (`1,5–2 недели`), метрики
   (`CPL`, `ДРР`, `ER`), диапазоны (`15–30 %`).
5. **Абзац — 3–5 предложений.** Первое — тезис, дальше — раскрытие и возражение.
6. **Заголовки без «мы»**: «Карточка, которая продаёт», не «Мы делаем карточки».
7. **FAQ отвечает по существу в первом предложении.** Дальше — детали и границы
   («если X — то Y»).
8. **Никакой воды про «команду профессионалов»** — её нет ни в одном блоке.
9. **Термины расшифровываются при первом упоминании:** `CPL (стоимость заявки)`,
   `ДРР (доля рекламных расходов)`, `FSM-сценарий`.
10. **Цены:** либо «считаем под задачу», либо диапазон с оговоркой. Не «от».

## 12. Анти-паттерны

| Нельзя | Почему |
|---|---|
| Третья строка в H1 | Ломает ритм hero и `leading-[1.06]` |
| Перенос строки 2 на две визуальные строки | Фраза рвётся на неудобном месте — укорачивать текст, не шрифт |
| Дублирование строки 1 в строке 2 | Читается как ошибка вёрстки |
| `font-bold` в заголовках | Контраст держится размером, не весом |
| Тени у обычных карточек | Тень = только hero-сайдбар и форма |
| Терракота как фон плашки | Акцент только текстом/иконкой |
| Вторая кнопка в hero | Один CTA — «Оставить заявку» → `#lead` |
| Eyebrow без номера или со сбитой нумерацией | Всегда `[NN / НАЗВАНИЕ]`, сервисные — `04.5+` |
| `[05]`, `[06]` для сервисных блоков | Сдвигает основную нумерацию |
| Выдуманное имя иконки | Glyph не отрисуется, останется текст |
| Контент, захардкоженный в шаблоне | Всё содержимое — только из `src/data/services/*` |
| Два блока с одинаковым фоном подряд | Пропадает граница секций |
| «Кому подходит» отдельной секцией | Убрано как шум, осталось строкой в сайдбаре |

## 13. Как добавить новый сервисный блок

1. Поле в `src/data/types.ts` (`Service`) с комментарием-назначением.
2. Данные в `src/data/services/<slug>.ts`.
3. Секция в `src/pages/services/[slug].astro` — между блоком `[04 / КАК РЕШАЕМ]`
   и FAQ, с условием `service.slug === '<slug>' && service.<field>`.
4. Eyebrow — следующий свободный `04.5 / 04.6 / 04.7`.
5. Фон — противоположный предыдущей секции.
6. Прогнать §11 и проверить в браузере.
