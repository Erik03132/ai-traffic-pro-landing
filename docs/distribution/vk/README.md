# VK — пакет постов

Собрано 18.11.2026. 11 текстов по 550–750 знаков (90–120 слов) + обложки из общего
пакета. Публикация — после создания сообщества и входа в VK.

## Формат

- Текст: один абзац-крючок, 3–6 коротких абзацев, ссылка на полную статью в конце,
  3–4 хештега последней строкой.
- Обложка: 1200×630, те же файлы, что для Дзена — VK показывает ленту в пропорции
  примерно 1,91:1, обрезки по краям не будет.
- Длина: до 750 знаков. Всё, что длиннее, VK прячет под «Показать полностью» —
  ссылка и хештеги уезжают в скрытую часть.

## Ритм

Раз в 2–3 дня, со сдвигом на сутки от публикации в Дзене: сначала статья на сайте
и в Дзене, потом пост в VK со ссылкой. Так VK не дублирует площадку в тот же час,
а ссылка ведёт на уже живую страницу.

## Что осталось

1. Войти в VK в браузере приложения (без этого постить некуда).
2. Создать сообщество «AI-TRAFFIC-PRO»: название, описание, аватар, обложка.
3. Опубликовать первые три поста вручную, дальше — по накатанной схеме.
