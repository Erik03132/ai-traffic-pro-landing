## 1. Что сделать в Telegram (3 минуты, руками)

1. Открыть Telegram → ☰ (меню) → **Создать канал** / **New Channel**.
2. **Название канала:** `AI-Traffic PRO` (видно в шапке, до @username).
3. **Описание канала** (вставьте текст из раздела 2).
4. Создать → **Настройки канала → Аватар** → загрузить
   `assets/distribution/telegram-avatar.png` (512×512, терракотовый квадрат с «AT»).
5. **Настройки канала → Имя пользователя** → `aitrafficpro`
   (если занято — `aitraffic_pro` или `ai_traffic_pro`; проверить можно на
   `t.me/aitrafficpro` — если страница не открывается, имя свободно).
6. **Настройки → Описание** → вставить то же описание (дублируется: одно — для
   профиля, второе — для закреплённого поста).
7. Открыть канал → **Закрепить сообщение** → вставить текст из раздела 3.

### Пост 2 — из статьи про CRM и ERP

```
CRM не заменяет учёт. ERP не ведёт продажи.

Это самая частая ошибка в компаниях, где решили «поставить CRM» — и не
самая дорогая. Обычно выходит так: менеджеры заводят сделки в табличке,
бухгалтерия ведёт учёт в 1С, а руководитель считает воронку по отчёту,
который собрали вручную. Систем две, цифры разные.

Разница простая. CRM хранит клиента: переписку, звонки, стадии сделки,
историю общения. ERP хранит ресурсы компании: склад, закупки, себестоимость,
счета, зарплату. Отсюда разные отчёты, разные пользователи и разные
требования к надёжности данных.

Рабочая схема у большинства: CRM принимает заявку и ведёт сделку, а когда
заказ нужно выполнить — передаёт его в ERP. Клиент при этом не переключают
между системами: он общается только с CRM.

Что делать, если CRM уже есть, но её обходят стороной — разобрали в статье:

https://ai-traffic-pro.ru/blog/crm-i-erp-raznica/?utm_source=telegram&utm_medium=social&utm_campaign=crm-i-erp-raznica
```

### Пост 3 — из статьи про медиаплан и контент-план

```
Медиаплан приводит людей. Контент-план даёт им причину остаться.

Публикации выходят регулярно, реклама настроена, а обращений нет. Обычно
в этом виноват не один из планов, а их отсутствие как пары: либо есть
контент-план без медиаплана (никто не показывает материалы), либо есть
медиаплан без контент-плана (люди приходят в пустой профиль и уходят).

Разница по существу: медиаплан — это деньги и показы (каналы, бюджет,
метрика, точка контроля), контент-план — это материалы и публикации
(рубрики, форматы, частота, ответственные). Это разные документы с разными
владельцами, и путать их — обычное дело.

Порядок простой: сначала деньги, потом материалы. Контент-план пишется под
те каналы, которые уже есть в медиаплане.

Подробно — в статье:
```

## 5. Правила канала (чтобы не превратить в анонсы)

| Правило | Почему |
|---------|--------|
| Пост — не анонс статьи, а отдельный тезис из неё | «у нас новая статья» читают только те, кто и так на сайте |
| Одна ссылка, в конце | ссылка в первом абзаце режет доверие и переходы |
| Один конкретный вывод на пост | правило проверки текста из `CONTENT_SPEC.md` §4a |
| Никаких цен и обещаний «лидов за неделю» | обещания без проверки = отписки |
| Ритм: 2–3 поста в неделю | лучше 2 сильных, чем 7 анонсов |
| Отвечать на каждый комментарий первые 2 месяца | комментарии = сигнал, что тема зашла |

```
https://ai-traffic-pro.ru/blog/<slug>/?utm_source=telegram&utm_medium=social&utm_campaign=<slug>
```

| Канал | `utm_source` | `utm_medium` |
|-------|--------------|--------------|

| Дзен | `dzen` | `social` |

статью привёл.
