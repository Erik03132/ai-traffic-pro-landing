## Как публиковать одну статью

1. Открыть файл, скопировать блок от строки после второго `---` до конца текста.
   Шапку файла (`**Заголовок:**`, `**Подзаголовок:**`, `**Теги:**`) **не копировать** — это подсказки.
2. В Студии вставить, затем оформить подзаголовки: строки-названия разделов → стиль «Заголовок»; строка-лид → «Подзаголовок».
3. Загрузить обложку из таблицы.
4. «Опубликовать» → «Настройки» → галочка **«Опубликовать позже»** → дата из таблицы, время **10:00 МСК**.
5. Тегов в редакторе нет — этот шаг пропускается.

## Правила, по которым собраны тексты

1. Таблицы переведены в списки: редактор Дзена таблиц не поддерживает.
2. HTML-ссылки заменены текстовыми: в Дзене они останутся кликабельными после вставки, но разметку редактор вычищает.
3. Ничего не дописано: все числа, примеры и оговорки взяты из статей блога. Новых кейсов и клиентов нет.
4. В конце каждого текста — ссылка на полную версию на сайте и подпись агентства.

## Что осталось на потом

- Подключение RSS: платформа требует 10 подписчиков канала, дальше статьи уходят сами.
- Перед подключением RSS добавить в ленту фильтр по слагам, которые уже вышли руками, иначе Дзен создаст дубли (см. `docs/adr/ADR-005-content-distribution.md`).
- Реестр дистрибуции (`docs/distribution/registry.json`) ведёт Telegram и VK: у Дзена нет API обратной связи, статусы ставятся глазами по этой таблице.
