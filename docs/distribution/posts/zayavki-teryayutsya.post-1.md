# Заявки теряются — пост 1 (канал @aitrafficpro)

Статья: `/blog/zayavki-teryayutsya/`
Статус: черновик, не опубликован.

---

Заявки теряются не в CRM, а между людьми.

Обращение пришло в мессенджер, где нет владельца. Менеджер ответил через сутки. После ответа не появилось следующего шага. На стыке отделов сделка растворилась. В отчётах при этом всё ровно: заявка есть, статус «в работе».

Чинить в этом порядке, без покупки системы:
1. одна точка входа для всех каналов;
2. срок первого ответа — и он измеряется;
3. обязательный следующий шаг после каждого разговора.

Это три изменения первой недели. CRM нужна позже — когда обращений больше, чем помещается в голову.
