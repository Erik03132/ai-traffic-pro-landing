# Семантическое ядро AI-Traffic PRO

Собрано 2026-10-28. Задача 2.1 (ROADMAP).

## Метод

- **Сбор формулировок:** Яндекс suggest + Google suggest + alphabet expand.
- **Частотность:** hh.ru — число вакансий по запросу (вся Россия, area=113).
- **Индекс интереса:** Google Trends, 0–100 за 12 месяцев, нормализован внутри батча.

> Wordstat и Keys.so недоступны (требуют оплаченного доступа) — числовых поисковых показов в ядре нет.
> Частотность hh.ru — прокси-метрика: объём спроса рынка труда, а не показы в поиске.
