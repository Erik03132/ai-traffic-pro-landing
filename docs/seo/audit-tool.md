# Публичный AI-аудит страницы (`/audit/`)

Статус: **Fixed и задеплоен 23.11.2026.** Проверено curl'ом на проде: страница
услуги `seo` → 100/100, приватный адрес → 422.

## Зачем

Внутренний линтер (`tools/geo_lint.py`) отвечает на вопрос «наша страница
готова». Публичный аудит отвечает на вопрос клиента «а моя?» — и работает как
вход в услугу: человек видит балл, список правок и форму заявки рядом.

Паттерн взят у overrank.ai (`Get a free SEO audit, takes 60 seconds`):
бесплатный разбор — лид-магнит, а отчёт пересылают внутри компании, поэтому
он приводит вторую волну трафика.

## Где что лежит

| Слой | Файл | Отвечает за |
|---|---|---|
| Правила | `worker/src/audit.js` | 8 блоков, веса, разбор HTML, SSRF-фильтр |
| API | `worker/src/index.js` → `handleAudit` | `POST /api/audit`, rate limit, коды ошибок |
| Страница | `src/pages/audit.astro` | тексты, таблица правил, FAQ, форма заявки |
| Интерфейс | `src/components/AuditWidget.astro` | форма, запрос, рендер отчёта |
| Лимит | `worker/wrangler.jsonc` | бак `AUDIT_LIMITER` — 3 запроса в минуту с IP |

## Паритет с внутренним линтером

`geo_lint.py` — источник истины. `audit.js` — его порт в Worker (там нет
Python). Паритет закреплён тестом на фикстуре
`worker/src/__fixtures__/article.html`:

```
python3 tools/geo_lint.py --file worker/src/__fixtures__/article.html  # → 98/100
node --test worker/src/audit.test.js                                   # → 98/100, те же блоки
```

**Меняете веса или правила — меняйте оба файла** и сверяйте прогоном выше.
Иначе публичный аудит начнёт обещать клиенту не то, что показывает внутренняя
приёмка.

Отличия от `geo_lint.py` (сознательные, два):

1. «Внутренняя ссылка» определяется по origin проверяемого сайта, а не по
   домену `ai-traffic-pro.ru` — аудит работает с чужими сайтами.
2. Блок «Ответ в начале» даёт 0 на странице короче 100 слов: иначе пустой URL
   получал 12/100 и отчёт врал.

## Безопасность

Аудит ходит по адресу, который ввёл посетитель, — это SSRF по определению.

- `safeUrl()` блокирует `localhost`, `*.local`, `*.internal`, приватные
  диапазоны IPv4 (10/8, 127/8, 172.16/12, 192.168/16, 169.254/16, 100.64/10),
  IPv6 (`::1`, `fc00::/7`, `fe80::/10`) и облачные метаданные.
- Адреса с логином и паролем и не-http схемы отклоняются.
- Таймаут 12 с на страницу, 6 с на `robots.txt`/`llms.txt`/`sitemap.xml`.
- Ответ обрезается до 400 КБ.
- `AUDIT_LIMITER` — 3 запроса в минуту с IP.
- Чужой текст (title, адреса) выводится **только** через `textContent`:
  `innerHTML` в виджете запрещён.
