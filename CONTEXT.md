# CONTEXT — доменные термины проекта AI-Traffic PRO

Один язык для контента, кода и обсуждений. Если термин встречается на сайте,
в данных (`src/data/services/*.ts`) или в задаче — здесь его определение и
правило употребления.

> Формат: **термин** — определение. В скобках: где живёт / как пишем на сайте.
> Новый термин → добавить сюда, а не объяснять в переписке.

---

## Сайт и стандарт страниц

| Термин | Определение |
|---|---|
| **Мультилендинг** | Страница услуги, собранная из фиксированного набора секций по единому стандарту. Все 7 страниц услуг — мультилендинги. Спека: `docs/design/SPEC-multi-landing.md` |
| **Сервисный блок** | Секция, которая есть только у одной услуги: `eyebrow` `04.5 / 04.6 / 04.7`. Например, «Этапы воронки» есть только у лидогенерации |
| **Eyebrow** | Моно-рубрика над заголовком секции: `[01 / ПРОБЛЕМЫ]`. JetBrains Mono, uppercase, терракота |
| **Accent-italic** | Курсивный акцент в заголовке: Instrument Serif italic, цвет `terracotta-600`. В H1 — всегда вторая строка |
| **Основная услуга** | Услуга с `num='01'…'06'`, `inMain=true` — есть на главной, в футере, сайте и сайтмапе |
| **Второстепенная услуга** | `num='—'`, `inMain=false` — нет на главной, но страница существует (сейчас — e-commerce) |
| **`inMain`** | Флаг в данных услуги: выводить ли карточку на главной странице |
| **Лид-форма** | Форма заявки на странице (`LeadForm.astro`), единственный `id="lead"` на странице |

## Маркетинг: каналы и воронка

| Термин | Определение |
|---|---|
| **Лид** | Обращение с контактными данными, из которого может получиться сделка. Не равно «клиент» |
| **Лидогенерация** | Работа по привлечению целевых обращений: каналы → путь до заявки → квалификация → передача в продажи |
| **Воронка** | Путь от первого касания до покупки: касание → интерес → заявка → квалификация → продажа. У каждого этапа своя метрика |
| **Квалификация лида** | Проверка обращения по критериям (задача, бюджет, сроки, роль в принятии решения). Отсеивает нецелевые до передачи менеджеру |
| **Скоринг** | Оценка заявки по ответам: целевая / тёплая / нецелевая. Определяет приоритет обработки |
| **Первое касание** | Первый контакт человека с брендом: объявление, пост, карточка на Авито, рекомендация |
| **CTA** | Призыв к действию. На страницах услуг один: «Оставить заявку» → `#lead` |
| **Ретаргетинг** | Показ рекламы тем, кто уже был на сайте или взаимодействовал с брендом |
| **Посевы** | Рекламные размещения в тематических Telegram-каналах и сообществах |
| **Лид-форма (в рекламе)** | Форма внутри площадки (VK, Avito): заявка без перехода на сайт |
| **Медиаплан** | Документ до запуска: задачи рекламы, каналы, форматы, бюджет, прогноз CPL, сроки тестов. Не путать с контент-планом (тот про темы и материалы) |
| **Контент-план** | Календарь публикаций: темы, рубрики, форматы, даты, площадки. Относится к органике, не к рекламе |

## Маркетинг: метрики

| Термин | Определение | Как пишем |
|---|---|---|
| **CPL** | Cost Per Lead — стоимость одной заявки: расход на трафик ÷ число целевых обращений | `CPL (стоимость заявки)` при первом упоминании |
| **Стоимость целевой заявки** | Расход ÷ число заявок, прошедших квалификацию. Всегда выше CPL — это нормально | отдельно от CPL, не смешивать |
| **CR** | Conversion Rate — конверсия: доля перешедших на следующий шаг | `CR в заявку`, `CR в сделку` |
| **CTR** | Click-Through Rate — доля кликов к показам | — |
| **ДРР** | Доля рекламных расходов: % выручки, ушедший на продвижение. Считается по карточке, категории, площадке | `ДРР (доля рекламных расходов)` |
| **ROMI** | Return on Marketing Investment — окупаемость маркетинга | `окупаемость (ROMI)` |
| **ER** | Engagement Rate — вовлечённость: (лайки + комменты + репосты) ÷ охват | — |
| **LCP / CLS / INP** | Core Web Vitals: скорость отрисовки, сдвиг вёрстки, отзывчивость. Замеряем на мобильном | — |
| **Сквозная аналитика** | Связка расход → обращение → сделка в одной системе (UTM + CRM) | — |
| **UTM** | Метки в ссылке, по которым видно источник, канал и креатив | `UTM-разметка`, `UTM-карта` |

## Каналы и площадки

| Термин | Определение |
|---|---|
| **Яндекс Директ** | Рекламная система Яндекса: Поиск (горячий спрос) + РСЯ (сети) |
| **РСЯ / КМС** | Рекламная сеть Яндекса: объявления на сайтах-партнёрах. Ловит тех, кто не искал прямо сейчас |
| **VK Реклама** | Таргетинг по интересам, сообществам, гео + лид-формы внутри площадки |
| **Telegram Ads** | Реклама в каналах по тематике и аудитории; низкий порог входа |
| **Avito** | Площадка с готовым намерением: «куплю», «ищу услугу», «сниму» |
| **Одноклассники** | Аудитория 35+ в регионах, высокая виральность репостов |
| **WB / Ozon / Яндекс Маркет** | Маркетплейсы. Аббревиатуры не расшифровываем на сайте — аудитория знает |
| **Свой интернет-магазин** | Собственный сайт с каталогом, корзиной и оплатой. Даёт клиентскую базу и контроль над ценами |

## E-commerce

| Термин | Определение |
|---|---|
| **Карточка товара** | Витрина позиции на площадке: заголовок, фото, характеристики, описание, отзывы |
| **Инфографика** | Изображения с выносками и цифрами поверх фото товара — по требованиям площадки |
| **Rich-контент** | Расширенный блок описания с изображениями и видео внутри карточки |
| **Выгрузка** | Передача каталога на площадку или в магазин: характеристики, фото, цены, остатки |
| **Фид** | Файл (обычно XML/YML) с данными каталога для автообновления на площадке |
| **FBO** | Fulfillment by Operator — товар на складе маркетплейса. Быстрее доставка, выше в выдаче, платное хранение |
| **FBS** | Fulfillment by Seller — отгрузка со своего склада. Контроль остатков, выше требования к скорости сборки |
| **Модерация** | Проверка карточки площадкой до публикации. Возврат с причиной = потерянные дни |
| **SOP** | Standard Operating Procedure — пошаговая инструкция процесса, чтобы его мог повторить сотрудник, а не только подрядчик |

## Технологии и автоматизация

| Термин | Определение |
|---|---|
| **CRM** | Система, где хранятся все обращения: кто, о чём, на каком этапе, что дальше |
| **amoCRM / Битрикс24 / HubSpot** | Основные CRM, с которыми работаем. Названия не переводим |
| **FSM-сценарий** | Finite State Machine — диалог бота по шагам: следующий вопрос зависит от предыдущего ответа |
| **Вебхук** | Автоматический HTTP-вызов при событии: заявка создалась → ушло уведомление |
| **Автоназначение** | Распределение заявки ответственному по правилам (загрузка, компетенция) |
| **Интеграционный слой** | Набор связок CRM с внешним миром: сайт, бот, реклама, телефония, почта |
| **Astro / Next.js / WordPress / Tilda** | Стек для сборки сайта. Astro — статика (быстро), Next.js — динамика, WordPress — самостоятельные правки, Tilda — запуск без разработки |
| **Прототип** | Схема страницы до дизайна: порядок блоков, сценарий, место формы |
| **Core Web Vitals** | Метрики скорости и стабильности вёрстки, которые учитывает Google |

## SEO и видимость в ИИ

| Термин | Определение |
|---|---|
| **SEO** | Работа с выдачей поисковой системы: позиция страницы по запросу |
| **GEO** | Generative Engine Optimization — попадание бренда в ответы нейросетей (Яндекс Нейро, ChatGPT, Perplexity). Позиции нет — есть упоминание или его отсутствие |
| **AEO** | Answer Engine Optimization — то же, но прицельно под ответы на вопросы |
| **Семантика** | Собранный реальный спрос: запросы, частотность, конкуренция |
| **Каннибализация** | Две страницы сайта конкурируют за один запрос — обе проигрывают |
| **Перелинковка** | Внутренние ссылки между страницами: какая страница отвечает на какой спрос |
| **Микроразметка / JSON-LD** | Машиночитаемое описание страницы для поиска и нейросетей |
| **Индексация** | Включение страницы в базу поисковика. Нет индексации — нет трафика |
| **sitemap.xml / robots.txt** | Карта сайта для роботов / правила обхода |

## Правила употребления

1. **Аббревиатуру расшифровываем при первом упоминании** на странице: `CPL (стоимость заявки)`, `ДРР (доля рекламных расходов)`, `FSM-сценарий`.
2. **Известные аудитории сокращения не трогаем**: `SEO`, `CRM`, `WB`, `Ozon`, `VK`, `SMM`.
3. **Не смешиваем метрики**: `CPL` ≠ `стоимость целевой заявки`; `медиаплан` ≠ `контент-план`.
4. **Термин один раз — одно значение.** Если в данных написано «площадки», это не «каналы»: каналы — про рекламу, площадки — про присутствие.
5. **Не придумываем термины ради текста.** Если явления нет в этом списке и оно не объяснимо одной фразой — скорее всего, оно не нужно на сайте.
