# AI-Traffic PRO — Landing Data

6 услуг digital-маркетинга для МСБ РФ 2026 + контактные виджеты (Telegram).

## Структура
- `src/data/services.ts` — 6 сервисных карточек + конфигурация контактных виджетов
- `src/data/contacts.ts` — (опционально) отдельный файл конфигурации виджетов

## Виджеты
1. **Chat bot widget** — `t.me/aibureau_bot` (всплывающий чат)
2. **TG form widget** — форма заявки через Telegram deep-link (без email)

## Услуги
1. Лидогенерация и продвижение
2. SMM и ведение соцсетей
3. SEO и видимость в ИИ
4. Контентная и таргетированная реклама
5. Сайт или лендинг под ключ
6. Маркетплейс-настройка (WB / Ozon / Автор)

## Исключено
Услуга №7 (AI-услуги) — исключена из проекта.
