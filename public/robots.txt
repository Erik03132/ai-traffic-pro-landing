# Правило: страницу исключаем из индекса только через <meta name="robots"
# content="noindex">, а не через Disallow. «noindex + Disallow» противоречиво —
# робот не читает noindex с закрытого URL, и в Search Console навсегда висит
# «Заблокировано файлом robots.txt» без возможности выйти из индекса.
#
# Сейчас:
#   /consent/ — noindex, вне sitemap (приложение к политике);
#   /privacy/ — индексируется, в sitemap (noindex снят 09.11, чтобы страница
#               могла попасть в индекс как самостоятельный документ).

# AI-краулеры: явное разрешение по именам.
# Формально «User-agent: * / Allow: /» уже пускает всех, но явный блок снимает
# вопрос в GEO-аудитах и оставляет намерение в файле, а не в голове: кого мы
# пускаем — видно. Цитирование в ответах нейросетей для нас канал привлечения,
# поэтому Disallow для них не ставим. Служебный манифест очереди публикаций
# (/distribution/) закрыт и для них: он не про контент сайта.
